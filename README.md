# Análisis del Desempeño Financiero con SQL

## Objetivo
Analizar el desempeño financiero de campañas en distintos países para identificar cuáles generaron mayor rentabilidad y eficiencia en relación con la inversión realizada.

## Herramientas
- SQL
- Excel

## Dataset
El análisis incluye información financiera de campañas en 6 países:
- United States
- Australia
- United Kingdom
- Germany
- France
- Canada

Las variables principales analizadas fueron:
- Ingresos
- Costos
- Beneficio bruto
- Margen de ganancia
- ROI

## Hallazgos
- United States fue el país más rentable, alcanzando más del 70% de ROI.
- Australia presentó el segundo ROI más alto del análisis.
- Canada obtuvo el margen de ganancia más alto, pero el ROI más bajo, indicando menor eficiencia de inversión.
- Los resultados muestran diferencias importantes entre margen y rentabilidad real según el nivel de inversión de cada campaña.
